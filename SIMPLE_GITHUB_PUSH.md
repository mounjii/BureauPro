# 🚀 Pousser le code sur GitHub - Guide Ultra Simple

## ⚡ Méthode la PLUS SIMPLE : GitHub Desktop

### Si vous avez GitHub Desktop installé :

1. **Ouvrez GitHub Desktop**

2. **Ajoutez votre projet :**
   - Cliquez sur **"File"** (en haut)
   - Cliquez sur **"Add Local Repository"**
   - Cliquez sur **"Choose..."**
   - Naviguez vers : `C:\Users\a\Desktop\bureaupro---catalogue-professionnel`
   - Cliquez sur **"Add repository"**

3. **Créez le commit :**
   - Vous verrez tous vos fichiers dans la liste
   - En bas à gauche, dans **"Summary"**, tapez :
     ```
     Initial commit - Burocycle app
     ```
   - Cliquez sur **"Commit to main"** (bouton bleu en bas)

4. **Publiez sur GitHub :**
   - Cliquez sur **"Publish repository"** (bouton en haut)
   - **Name :** `BUROCYCLE` (ou laissez tel quel)
   - **Description :** (optionnel)
   - Décochez **"Keep this code private"** si vous voulez que ce soit public
   - Cliquez sur **"Publish repository"**

5. **✅ C'est fait !** Votre code est sur GitHub !

## 🔧 Si GitHub Desktop n'est PAS installé :

### Option A : Installer GitHub Desktop (RECOMMANDÉ)

1. Allez sur : **https://desktop.github.com**
2. Cliquez sur **"Download for Windows"**
3. Installez-le
4. Connectez-vous avec votre compte GitHub (`mounjii`)
5. Suivez les étapes ci-dessus

### Option B : Installer Git en ligne de commande

1. Allez sur : **https://git-scm.com/download/win**
2. Téléchargez Git
3. Installez-le (gardez toutes les options par défaut)
4. **IMPORTANT :** Redémarrez votre terminal/PowerShell
5. Double-cliquez à nouveau sur `push-to-github.bat`

## 📋 Résumé rapide

**Avec GitHub Desktop (5 minutes) :**
1. Ouvrir GitHub Desktop
2. File → Add Local Repository
3. Sélectionner votre dossier
4. Commit → Publish repository
5. ✅ Terminé !

**Sans GitHub Desktop :**
1. Installer Git : https://git-scm.com/download/win
2. Redémarrer le terminal
3. Relancer `push-to-github.bat`

---

## 🎯 Quelle méthode choisir ?

- **GitHub Desktop** = Plus simple, interface graphique, pas besoin de ligne de commande
- **Git CLI** = Plus de contrôle, mais nécessite la ligne de commande

**Recommandation :** Utilisez GitHub Desktop si vous n'êtes pas à l'aise avec la ligne de commande.
