# 📤 Guide GitHub Desktop - Pousser le code

## 🎯 Utiliser GitHub Desktop (Plus simple !)

### Étape 1 : Ouvrir GitHub Desktop

1. Ouvrez **GitHub Desktop** (si pas déjà ouvert)
2. Connectez-vous avec votre compte GitHub (`mounjii`)

### Étape 2 : Ajouter votre projet local

1. Dans GitHub Desktop, cliquez sur **"File"** → **"Add Local Repository"**
2. Cliquez sur **"Choose..."**
3. Naviguez vers : `C:\Users\a\Desktop\bureaupro---catalogue-professionnel`
4. Cliquez sur **"Add repository"**

### Étape 3 : Vérifier les fichiers

1. Vous devriez voir tous vos fichiers dans la liste
2. En bas, vous verrez un message comme "X files changed"
3. Si vous voyez des fichiers, c'est bon !

### Étape 4 : Créer le commit

1. En bas à gauche, dans la zone **"Summary"**, tapez :
   ```
   Initial commit - Burocycle app with Cloudinary and deployment config
   ```
2. Cliquez sur **"Commit to main"** (en bas)

### Étape 5 : Publier sur GitHub

1. Cliquez sur **"Publish repository"** (bouton en haut)
2. Dans la fenêtre qui s'ouvre :
   - **Name :** `BUROCYCLE` (ou laissez tel quel)
   - **Description :** (optionnel) "Burocycle - Catalogue professionnel"
   - **Keep this code private :** Décochez si vous voulez que ce soit public
3. Cliquez sur **"Publish repository"**

### ✅ C'est fait !

Votre code est maintenant sur GitHub ! Vous pouvez vérifier sur :
**https://github.com/mounjii/BUROCYCLE**

---

## 🔄 Pour les prochaines modifications

À chaque fois que vous modifiez des fichiers :

1. GitHub Desktop détecte automatiquement les changements
2. Vous verrez les fichiers modifiés dans la liste
3. Ajoutez un message de commit (ex: "Update dashboard")
4. Cliquez sur **"Commit to main"**
5. Cliquez sur **"Push origin"** (en haut) pour envoyer sur GitHub

---

## 🐛 Si GitHub Desktop n'est pas installé

1. Téléchargez : **https://desktop.github.com**
2. Installez-le
3. Connectez-vous avec votre compte GitHub
4. Suivez les étapes ci-dessus

---

## 📝 Alternative : Installer Git en ligne de commande

Si vous préférez utiliser la ligne de commande :

1. Téléchargez Git : **https://git-scm.com/download/win**
2. Installez-le (gardez toutes les options par défaut)
3. **Redémarrez votre terminal/PowerShell**
4. Utilisez les commandes dans `GITHUB_PUSH_COMMANDS.md`
