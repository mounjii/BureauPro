# 🚀 GitHub Desktop - Guide Rapide

## ✅ Étapes à suivre (5 minutes)

### 1. Ouvrir GitHub Desktop
- Ouvrez **GitHub Desktop** (cherchez dans le menu Démarrer)

### 2. Se connecter (si pas déjà fait)
- Cliquez sur **"Sign in to GitHub.com"**
- Connectez-vous avec votre compte GitHub (`mounjii`)

### 3. Ajouter votre projet local
- Cliquez sur **"File"** (en haut à gauche)
- Cliquez sur **"Add Local Repository"**
- Cliquez sur **"Choose..."**
- Naviguez vers : `C:\Users\a\Desktop\bureaupro---catalogue-professionnel`
- Cliquez sur **"Add repository"**

### 4. Créer le commit
- Vous verrez tous vos fichiers dans la liste (à gauche)
- En bas à gauche, dans **"Summary"**, tapez :
  ```
  Initial commit - Burocycle app
  ```
- Cliquez sur **"Commit to main"** (bouton bleu en bas)

### 5. Publier sur GitHub
- Cliquez sur **"Publish repository"** (bouton en haut)
- Dans la fenêtre :
  - **Name :** `BUROCYCLE` (ou laissez tel quel)
  - Décochez **"Keep this code private"** si vous voulez que ce soit public
- Cliquez sur **"Publish repository"**

### ✅ Terminé !
Votre code est maintenant sur GitHub : **https://github.com/mounjii/BUROCYCLE**
